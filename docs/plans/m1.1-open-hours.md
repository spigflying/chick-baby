# M1.1 開放時間（夜間睡覺）+ 部署前改動 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓遊戲只在平日 09:00–20:00 開放，休息時段時間凍結、伺服器在資料庫停機時也能啟動；同時完成部署前必要的三項改動（分頁隱藏或閒置斷線、連線池 8、無資料庫啟動）。

**Architecture:**
- 共用引擎新增一個決定性的「開放時間時鐘」（`Clock`）。寵物模擬只在開放時段內一分鐘一分鐘地累計，每跨過一次開門時間就觸發早安。
- 伺服器用 `OPEN_HOURS` 環境變數建立時鐘：
  - 以「資料庫閘門」延後 migration 和 LISTEN 到第一次需要資料庫時才執行。
  - 用 HTTP hook 與 WebSocket 擋掉休息時段的請求。
  - 用一個每秒檢查的排程處理 19:55／20:00 的關門流程。
- 前端開頁先問 `/api/status`，休息時段只顯示睡覺畫面；開放時間內分頁隱藏或閒置就暫停 WebSocket。

**Tech Stack:** Node 22、TypeScript（strict）、pnpm 10 workspaces（透過 `corepack pnpm`）、Fastify 5 + @fastify/websocket 11、Kysely + pg、Vite 5、Vitest 2。

## Global Constraints

- 開放時間格式：`OPEN_HOURS=mon-fri 09:00-20:00 Asia/Taipei`。沒設 = 永遠開放（本機開發與既有測試）。只支援 `Asia/Taipei`、`UTC` 兩個時區。
- 開放區間 `[09:00, 20:00)`：09:00:00 算開放，20:00:00 算關門。
- 「快關門」= 關門前 5 分鐘（19:55 起）：不能開新的下樓梯，並廣播 `game.closing {closes_at}`。
- 20:00：進行中的下樓梯標記 `aborted`（不發獎勵、不扣精力），廣播 `game.closed {opens_at}` 後關閉 WebSocket（close code 4423）；前端不自動重連。
- 早安：精力設為 `GAME.morningEnergy`（預設 100），`sleeping = false`，寫 `pet_events`（`wake`，payload `{reason: "morning"}`）；蛋與死亡寵物不適用。
- 錯誤碼：`GAME_CLOSED` → HTTP 423（附 `opens_at`）、`GAME_CLOSING` → 423、`DB_UNAVAILABLE` → 503。
- `GET /api/status`、`GET /api/config`、`/healthz` 不能碰資料庫；`POST /api/internal/daily` 不受關門限制（它在 20:05 執行）。
- 連線池 `max: 8`（Cloud SQL f1-micro 只有 25 條連線：2 × 8 + 2 條 LISTEN = 18）。
- 暫停連線：分頁隱藏 ≥ 2 分鐘，或 ≥ 10 分鐘沒有操作；比賽中不暫停。
- 引擎必須決定性：不使用 `Math.random()`、不讀系統時區（時區由 `offsetMin` 決定）。
- UI 文字用繁體中文；程式註解沿用 repo 的中文短註解風格。
- 指令一律用 `corepack pnpm …`（本機沒有全域 pnpm；根目錄 script 內部呼叫 `pnpm` 會失敗，所以逐個套件執行）。
- 需要 Postgres 的整合測試（`apps/server/test/api.test.ts`）要先 `docker compose up -d`；本次驗證時沒有開 Docker，見 Task 5 的注意。
- 這個 repo 直接 commit 並 push 到 `main`（不開 branch / PR）。

## Review Focus

規格有隱含、但容易被忽略的五種情況（已經各自補上測試）：

1. **09:00 開門時很多人同時進來**：migration 與 LISTEN 只能執行一次，不能每個請求都跑。→ Task 4 `gate.test.ts`「runs migration and LISTEN once even when many requests arrive together」。
2. **夜間資料庫停機**：LISTEN 連線失敗必須乾淨地丟出錯誤，不能讓程式崩潰，也不能每秒重連洗版 log。→ Task 4 `boot.test.ts`「Bus.start against a stopped DB rejects quickly instead of crashing」，加上 `Bus` 的指數退避。
3. **很久沒人碰的寵物**（放了好幾週）：只累計開放時間，而且結算要快。→ Task 1「elapsed over four weeks is 20 weekdays × 11 hours」、Task 2「a neglected pet survives the weekend」。
4. **剛好在 20:00 寫入**：WebSocket 的動作不經過 HTTP hook，必須在 transaction 內再擋一次，而且不能有扣幣等副作用。→ Task 5「the transaction-level check rejects WS writes without side effects」（需要 Postgres）。
5. **暫停連線後回來**：要重新連線並同步狀態；比賽中絕不暫停。→ Task 6 `idle.test.ts`「never pauses during a match」，加上 Task 8 Step 3 的手動檢查。

/**
 * 開放時間（requirements §4.7）：遊戲只在開放時間內計時，休息時段時間凍結。
 * 只支援固定時差的時區（不處理夏令時間），所以結果完全決定性。
 */
export interface OpenHours { days: number[]; openMin: number; closeMin: number; offsetMin: number }
export interface OpenStatus { open: boolean; opens_at: number | null; closes_at: number | null }
export type Phase = 'open' | 'closing' | 'closed';
export interface Clock {
  alwaysOpen: boolean;
  isOpen(t: number): boolean;
  /** [from, to) 之中落在開放時間的區間，依時間排序。 */
  segments(from: number, to: number): [number, number][];
  /** [a, b) 之中的開放毫秒數。 */
  elapsed(a: number, b: number): number;
  /** 從 from 起累計 ms 開放毫秒後的時間點；永遠不開放時回傳 Infinity。 */
  addOpen(from: number, ms: number): number;
  /** 開門時間點 O，滿足 from < O ≤ to（用來觸發「早安」）。 */
  openingsIn(from: number, to: number): number[];
  status(t: number): OpenStatus;
}

const DAY = 86_400_000;
const MIN = 60_000;
const DAY_NAMES = ['sun', 'mon', 'tue', 'wed', 'thu', 'fri', 'sat'];
const TZ_OFFSET_MIN: Record<string, number> = { 'Asia/Taipei': 480, UTC: 0 };
/** 關門前幾毫秒開始「快關門」（停止開新局、廣播 game.closing）。 */
export const CLOSING_WARN_MS = 5 * MIN;

/** 解析 `mon-fri 09:00-20:00 Asia/Taipei`。 */
export function parseOpenHours(s: string): OpenHours {
  const m = /^([a-z]{3})-([a-z]{3}) (\d\d):(\d\d)-(\d\d):(\d\d) (\S+)$/i.exec(s.trim());
  if (!m) throw new Error(`OPEN_HOURS 格式錯誤：${s}`);
  const d0 = DAY_NAMES.indexOf(m[1].toLowerCase()), d1 = DAY_NAMES.indexOf(m[2].toLowerCase());
  if (d0 < 0 || d1 < 0 || d1 < d0) throw new Error(`OPEN_HOURS 星期錯誤：${s}`);
  const openMin = +m[3] * 60 + +m[4], closeMin = +m[5] * 60 + +m[6];
  if (!(openMin < closeMin && closeMin <= 24 * 60)) throw new Error(`OPEN_HOURS 時間錯誤：${s}`);
  const offsetMin = TZ_OFFSET_MIN[m[7]];
  if (offsetMin === undefined) throw new Error(`OPEN_HOURS 不支援的時區：${m[7]}`);
  const days: number[] = [];
  for (let d = d0; d <= d1; d++) days.push(d);
  return { days, openMin, closeMin, offsetMin };
}

export const ALWAYS_OPEN: Clock = {
  alwaysOpen: true,
  isOpen: () => true,
  segments: (from, to) => (to > from ? [[from, to]] : []),
  elapsed: (a, b) => Math.max(0, b - a),
  addOpen: (from, ms) => from + ms,
  openingsIn: () => [],
  status: () => ({ open: true, opens_at: null, closes_at: null }),
};

export function makeClock(h: OpenHours): Clock {
  const off = h.offsetMin * MIN;
  const dayIndex = (t: number) => Math.floor((t + off) / DAY);
  const dayStart = (d: number) => d * DAY - off;
  const weekday = (d: number) => (((d + 4) % 7) + 7) % 7; // 1970-01-01 是星期四
  const segOfDay = (d: number): [number, number] | null => {
    if (!h.days.includes(weekday(d))) return null;
    const s = dayStart(d);
    return [s + h.openMin * MIN, s + h.closeMin * MIN];
  };
  const segments = (from: number, to: number) => {
    const out: [number, number][] = [];
    if (to <= from) return out;
    for (let d = dayIndex(from); dayStart(d) < to; d++) {
      const g = segOfDay(d); if (!g) continue;
      const a = Math.max(g[0], from), b = Math.min(g[1], to);
      if (a < b) out.push([a, b]);
    }
    return out;
  };
  const isOpen = (t: number) => { const g = segOfDay(dayIndex(t)); return !!g && t >= g[0] && t < g[1]; };
  /** t 之後（含 t）第一個開門時間；兩週內都沒有就回傳 null。 */
  const nextOpening = (t: number) => {
    for (let d = dayIndex(t); d <= dayIndex(t) + 14; d++) { const g = segOfDay(d); if (g && g[0] >= t) return g[0]; }
    return null;
  };
  return {
    alwaysOpen: false,
    isOpen,
    segments,
    elapsed: (a, b) => segments(a, b).reduce((sum, [x, y]) => sum + (y - x), 0),
    addOpen(from, ms) {
      if (!h.days.length) return Infinity;
      let rem = ms;
      for (let d = dayIndex(from); ; d++) {
        const g = segOfDay(d); if (!g) continue;
        const a = Math.max(g[0], from); if (a >= g[1]) continue;
        if (rem <= g[1] - a) return a + rem;
        rem -= g[1] - a;
      }
    },
    openingsIn(from, to) {
      const out: number[] = [];
      for (let d = dayIndex(from); dayStart(d) <= to; d++) { const g = segOfDay(d); if (g && g[0] > from && g[0] <= to) out.push(g[0]); }
      return out;
    },
    status(t) {
      if (isOpen(t)) { const g = segOfDay(dayIndex(t))!; return { open: true, closes_at: g[1], opens_at: nextOpening(g[1]) }; }
      return { open: false, closes_at: null, opens_at: nextOpening(t) };
    },
  };
}

/** 開放中、快關門（關門前 CLOSING_WARN_MS 內）或已關門。 */
export function phaseAt(clock: Clock, t: number): Phase {
  const s = clock.status(t);
  if (!s.open) return 'closed';
  return s.closes_at !== null && s.closes_at - t <= CLOSING_WARN_MS ? 'closing' : 'open';
}

export function startClosingLoop(h: ClosingHandlers, now: () => number = Date.now, intervalMs = 1000) {
  let prev: Phase = phaseAt(clock(), now());
  const tick = async () => {
    const t = now(), cur = phaseAt(clock(), t);
    if (cur === prev) return;
    prev = cur;
    if (cur === 'closing') await h.onClosing(clock().status(t).closes_at!);
    else if (cur === 'closed') await h.onClosed(clock().status(t).opens_at);
  };
  const timer = setInterval(() => { tick().catch((e) => console.error('closing loop failed', e)); }, intervalMs);
  timer.unref();
  return { timer, tick };
}

export function createDbGate(db: Db, bus: Bus, migrate: (db: Db) => Promise<unknown> = migrateToLatest) {

import type { Live } from './ws';

export interface IdleConfig { hiddenMs: number; idleMs: number }
/** 分頁隱藏 2 分鐘、或 10 分鐘沒有操作 → 暫停連線（gcp-plan §6.1：開著的 WebSocket 會讓 Cloud Run 一直計費）。 */
export const IDLE: IdleConfig = { hiddenMs: 2 * 60_000, idleMs: 10 * 60_000 };
export interface IdleState { hiddenSince: number | null; lastActivity: number; inMatch: boolean }

export function shouldPause(s: IdleState, now: number, cfg: IdleConfig = IDLE): boolean {
  if (s.inMatch) return false; // 比賽中不斷線
  if (s.hiddenSince !== null && now - s.hiddenSince >= cfg.hiddenMs) return true;
  return now - s.lastActivity >= cfg.idleMs;
}

/** 接上瀏覽器事件：隱藏或閒置就 live.pause()，回到分頁或有操作就 live.resume()。回傳解除函式。 */
export function watchIdle(live: Live, cfg: IdleConfig = IDLE): () => void {
  const s: IdleState = { hiddenSince: document.hidden ? Date.now() : null, lastActivity: Date.now(), inMatch: false };
  const wake = () => { s.lastActivity = Date.now(); if (live.isPaused) live.resume(); };
  const onVis = () => { if (document.hidden) s.hiddenSince = Date.now(); else { s.hiddenSince = null; wake(); } };
  const events = ['pointerdown', 'keydown', 'touchstart'] as const;
  document.addEventListener('visibilitychange', onVis);
  events.forEach((e) => window.addEventListener(e, wake, { passive: true }));
  const timer = window.setInterval(() => { s.inMatch = live.inMatch; if (!live.isPaused && shouldPause(s, Date.now(), cfg)) live.pause(); }, 5000);
  return () => { clearInterval(timer); document.removeEventListener('visibilitychange', onVis); events.forEach((e) => window.removeEventListener(e, wake)); };
}

  const d = Math.floor(s / 86400), h = Math.floor((s % 86400) / 3600), m = Math.floor((s % 3600) / 60), sec = s % 60;
  const hms = [h, m, sec].map((v) => String(v).padStart(2, '0')).join(':');
  return d ? `${d} 天 ${hms}` : hms;
}
/** 開門時間（瀏覽器時區；台灣使用者即台北時間）：`星期一 09:00`。 */
export function formatOpensAt(t: number): string {
  const d = new Date(t);
  return `星期${'日一二三四五六'[d.getDay()]} ${String(d.getHours()).padStart(2, '0')}:${String(d.getMinutes()).padStart(2, '0')}`;
}
