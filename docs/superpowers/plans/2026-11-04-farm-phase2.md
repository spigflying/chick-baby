# 小雞農場第二階段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** East expansion area with bought fields, beehive/cowshed/dairy, honey cake, hot-air balloon deliveries, decorations, player stalls, feeding the pet from the barn, chick watering linked to pet stamina.

**Architecture:** Same as phase 1: rules are pure functions in `packages/engine/src/farm.ts` over one `FarmState` jsonb; server adds permission, locking, ledger, caps; web adds an EAST scene toggled from the main scene.

**Tech Stack:** TypeScript, Vitest, Fastify + Kysely + Postgres, Vite, SVG.

**Spec:** `docs/superpowers/specs/2026-11-04-farm-phase2-design.md` (phase 1: `2026-11-03-farm-design.md`)

## Global Constraints

- Branch `farm` in worktree `../chick-baby-farm`; nothing on main; no push.
- Everything stays behind `FARM_ENABLED`.
- Timers only count open time (`clock.addOpen` / `clock.elapsed`).
- PC only; no drag gestures.
- Old saves must load (`loadFarm` fills every new field).
- Colors: no Game Boy greens (`#9bbc0f #8bac0f #306230 #0f380f`).

## Review Focus

1. Stall buy race: two buyers hit the same slot at once → exactly one succeeds (both farms locked in sorted order).
2. A pre-phase-2 save (no new fields, 12 fields) loads and keeps all its state.
3. Balloon expiring while the player is offline: unfilled crates vanish, no coins taken, the next balloon comes 3 open hours after `leave`.
4. Feeding the pet from the farm while the pet is asleep or dead: rejected, and the item stays in the barn.
5. Chick-water count resets on the next Taipei day, and its limit follows the pet's current stamina.
