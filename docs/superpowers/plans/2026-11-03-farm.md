# 小雞農場 第一階段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出只限電腦玩的「小雞農場」：種田、動物、果樹、加工、訂單、倉庫、等級、好友幫忙，伺服器權威，彩色可愛插畫風全頁畫面。

**Architecture:** 整座農場是一個 `FarmState` 物件，規則全部是 `packages/engine/src/farm.ts` 的純函式（同一套給伺服器、經濟模擬、測試用）。伺服器把狀態存成 `farms.state jsonb`（一人一列，`FOR UPDATE` 鎖住後套用動作再寫回），金幣走既有 `changeBalance`，冪等稽核走既有 `runAction`。前端 `farm-view.ts` 是蓋在蛋殼頁上的全頁 SVG 畫面，掛法同 `fight-view.ts`。

**Tech Stack:** TypeScript、pnpm monorepo、Fastify + Kysely + Postgres、Vite、Vitest。

**Spec:** `docs/superpowers/specs/2026-11-03-farm-design.md`（畫面基準：`https://claude.ai/artifact/EpkbR3MwNeRZaTVnfBtT3n` 第 3 版，原始檔在 session scratchpad 的 `farm-mockup.html`，Task 5 會把它的圖形搬進 repo）

## Global Constraints

- **跟格鬥分開部署**：全部工作在 git worktree 的 `farm` 分支，**不 commit 到 main、不 push main**。main 照常給格鬥部署。`farm` 分支要不要 push 等 Benson 說（「cmp」才 commit＋push）。
- **開關**：伺服器環境變數 `FARM_ENABLED=1` 才註冊農場 API、`/api/config` 才回 `farm: true`、前端才出現「農場」格子。沒設＝完全看不到（合併到 main 也不會曝光）。
- **只限電腦**：前端用 `live.touch`（`matchMedia('(pointer:coarse)')`）判斷；手機上「農場」格子顯示成灰色，點了 `say('農場只能用電腦玩')`。伺服器不檢查裝置。
- **時間只算開放時間**：所有計時用 `clock.addOpen(from, ms)` 算 `ready`，用 `clock.elapsed(a, b)` 算經過比例。
- **金幣共用錢包 ◎**，帳本 reason 只能用：`farm_seed`、`farm_sell`、`farm_order`、`farm_upgrade`、`farm_level`、`farm_rescue`。沒有第二種貨幣；友情點數存在農場狀態裡，不能換金幣。
- **不能偷菜**；農場跟寵物不連動；一人一座農場綁 `user_id`。
- **Migration 名稱 `0011_farm`**。合併回 main 前若 main 已經有 `0011_*`，改成下一個沒用過的號碼（本機開發資料庫要刪 `kysely_migration` 那一列再重跑）。
- **作者**：commit 前 `git var GIT_AUTHOR_IDENT` 要是 `spigflying`；在 worktree 裡**不要**設 `git config user.*`。
- **美術**：不用像素風、不用四階綠；向量 SVG；粉 `#ff8fab`、薄荷 `#7fd6b4`、奶油黃 `#ffd166`、天空藍 `#9ad7ff`、紫 `#c38cff`、墨色 `#4b3a33`；圓體 `Huninn`（Google Fonts）＋ `"PingFang TC","Noto Sans TC",system-ui` fallback；`prefers-reduced-motion` 時動畫全關。不能出現原作角色、名稱或可辨認造型。
- **文案**：繁體中文，玩家看得懂的說法（「可收成」「倉庫滿了」），錯誤訊息講原因和怎麼辦。

## Review Focus

1. **19:59 種下的作物**：應該在下一個開放日早上才熟，畫面倒數顯示的是開放時間的剩餘量，不是牆鐘時間（Task 1 測試 `plant at 19:59 ripens next open day`）。
2. **重複點擊／兩個分頁同時操作**：同一塊田不能收兩次、金幣不能入帳兩次（Task 3 測試 `concurrent harvest pays once`、`replayed request_id`）。
3. **倉庫快滿時一鍵收全部**：收到滿為止，沒收的田維持可收成，東西不會消失（Task 1 測試 `collectAll stops at barn cap`）。
4. **幫忙的權限與上限**：黑名單、`closed` 家、自己幫自己都拒絕；每天 10／同農場 5 次在台北日期換日時重置（Task 3 測試 `help permissions`、`help daily caps`）。
5. **舊存檔與之後加內容**：缺欄位的 `state`（例如以後加了新建築）讀進來要補預設值、不能壞；訂單永遠不出還沒解鎖的東西（Task 1 測試 `loadFarm fills defaults`、`orders only use unlocked items`）。

  export type AnimalStation = 'hutch' | 'coop';

  export interface Stack { item: ItemId; qty: number }
  export interface Field { crop: CropId | null; start: number; ready: number; wateredBy: string | null }
  export interface Animal { start: number; ready: number | null }       // ready null = 還沒餵
  export interface Job { recipe: RecipeId; ready: number }

  export interface HelpNote { by: string; name: string; kind: 'water' | 'rescue'; at: number }
  export interface FarmState {
    v: 1; seed: number; level: number; xp: number; friendPts: number;
    barnLevel: number; barnBonus: number; barnBonusBought: number;
    fields: Field[];                                   // 長度 12
    animals: Record<AnimalStation, Animal[]>;          // 各 2 隻
    tree: { start: number; ready: number };
    jobs: Record<CraftStation, Job[]>; queueSlots: Record<CraftStation, number>;
    inv: Partial<Record<ItemId, number>>;
    orders: (Order | null)[]; orderWait: number[]; orderSeq: number;   // 長度 6
    helpLog: HelpNote[];                               // 最多保留 20 筆
  }
  export type FarmAction =
    | { type: 'plant'; idx: number; crop: CropId } | { type: 'harvest'; idx: number } | { type: 'collectAll' }
    | { type: 'feed'; station: AnimalStation; i: number } | { type: 'collect'; station: AnimalStation; i: number }
    | { type: 'tree' } | { type: 'rescue' }
    | { type: 'craft'; recipe: RecipeId } | { type: 'collectJobs'; station: CraftStation }
    | { type: 'deliver'; slot: number } | { type: 'discard'; slot: number } | { type: 'sell'; item: ItemId; qty: number }
    | { type: 'upgradeBarn' } | { type: 'upgradeQueue'; station: CraftStation } | { type: 'barnBonus' } | { type: 'ackHelp' };
  export type HelpAction = { kind: 'water'; idx: number } | { kind: 'rescue' };
  export interface FarmOutcome { ledger: { reason: FarmReason; delta: number }[]; leveled: number[] }
  export class FarmError extends Error { constructor(public code: FarmErrorCode) }
  export type FarmErrorCode = 'BAD_REQUEST' | 'NOT_UNLOCKED' | 'SLOT_BUSY' | 'NOT_READY' | 'BARN_FULL' | 'NOT_ENOUGH_ITEMS'
    | 'QUEUE_FULL' | 'WITHERED' | 'NOT_WITHERED' | 'ALREADY_WATERED' | 'NOT_GROWING' | 'MAX_LEVEL' | 'NOT_ENOUGH_FRIEND_POINTS' | 'NO_ORDER';
  export const FARM: { /* 上表全部數值 */ };
  export const ITEMS: Record<ItemId, { name: string; sell: number; xp: number }>;
  export const CROPS: Record<CropId, { name: string; level: number; growMs: number; seedCoins: number; seedFriendPts: number; out: Stack }>;
  export const ANIMALS: Record<AnimalStation, { name: string; animal: string; level: number; ms: number; feed: Stack[]; out: Stack }>;
  export const RECIPES: Record<RecipeId, { name: string; station: CraftStation; level: number; ms: number; in: Stack[]; out: Stack }>;
  export function newFarm(seed: number, now: number, clock: Clock): FarmState;
  export function loadFarm(json: unknown, now: number, clock: Clock): FarmState;   // 補預設值、v 升級
  export function fieldsUnlocked(level: number): number;
  export function orderSlots(level: number): number;
  export function barnCap(s: FarmState): number;
  export function invCount(s: FarmState): number;
  export function refreshOrders(s: FarmState, now: number): void;                   // 補空的訂單格（決定性：seed + orderSeq）
  export function genOrder(seed: number, seq: number, level: number): Order;
  export function applyFarm(s: FarmState, a: FarmAction, now: number, clock: Clock): FarmOutcome;
  export function applyHelp(s: FarmState, a: HelpAction, helper: { id: string; name: string }, now: number, clock: Clock): void;
  export type Stage = 0 | 1 | 2 | 3;     // 剛播種、發芽、長葉子、可收成
  export function stageOf(start: number, ready: number, now: number, clock: Clock): Stage;
  export function treeWithered(s: FarmState, now: number, clock: Clock): boolean;
  export interface FarmDerived {
    fields: { stage: Stage | null; remainMs: number; locked: boolean; unlockLevel: number }[];
    animals: Record<AnimalStation, { locked: boolean; items: { state: 'hungry' | 'growing' | 'ready'; remainMs: number }[] }>;
    tree: { state: 'growing' | 'ready' | 'withered'; remainMs: number };
    jobs: Record<CraftStation, { locked: boolean; items: { recipe: RecipeId; remainMs: number }[] }>;
