# 🐣 小雞寶寶 chick-baby

一款用純 HTML / CSS / JavaScript 製作的網頁版電子雞（Tamagotchi），不需要任何建置步驟，手機也能玩！

線上遊玩：https://spigflying.github.io/chick-baby/

## 特色
- 復古像素風：彩色像素蛋殼外殼，加上 Game Boy 四色綠螢幕，所有操作都在螢幕內完成
- 五項狀態：飽食度、快樂度、精力、清潔度、健康，會隨真實時間下降
- 成長階段：蛋（0–2 分鐘）→ 小雞（2–60 分鐘）→ 大雞（60 分鐘以上）
- 可以幫寵物取名字
- 照顧不好會生病 🤒、會便便 💩，健康歸零就會死掉，可以重新開始
- 進度自動存在瀏覽器 localStorage，關掉網頁後再打開，會計算離線期間的狀態變化

## 怎麼玩
1. 打開網頁，輸入名字開始孵蛋
2. 點螢幕下方的像素圖示（或用鍵盤 ←→ 選擇、Enter 確定、Esc 返回）：
   - 🍗 **餵食**：開啟食物選單，蛋糕等食物在長大後才會解鎖
     | 食物 | 解鎖 | 飽食 | 快樂 | 健康 | 體重 | 力量 | 速度 | 體力 |
     |---|---|---|---|---|---|---|---|---|
     | 米粒 | 小雞 | +20 | +2 | +1 | +1 | | | +1 |
     | 蟲蟲 | 小雞 | +15 | +6 | +2 | +1 | +2 | +0.5 | |
     | 糖果（點心） | 小雞 | +5 | +15 | -3 | +2 | | | |
     | 玉米 | 大雞 | +30 | +4 | +2 | +2 | +1 | +1 | +2 |
     | 蛋糕（點心） | 大雞 | +10 | +25 | -5 | +4 | | -0.5 | |
   - 🎾 **玩耍**：快樂度上升、速度提升、體重下降
   - 🌙 **睡覺**：恢復精力、體力提升；再按一次叫醒
   - 💧 **清潔**：清掉便便
   - ✚ **看醫生**：治療生病
   - 📊 **狀態**：查看力量、速度、體力、體重、性格、出生時間與 ID
3. 數值太低會讓健康下降，健康歸零寵物就會死掉，點畫面就能重新開始

## 資料格式
存檔放在 localStorage（`chickBabyState`），格式為 `schemaVersion: 2` 的單一 JSON 物件，包含 `id`、`birthTime` 和 `traits`（力量、速度、體力、體重、性格）。這份 JSON 之後可以直接寫進 Firestore 文件；舊版存檔會自動轉換成新格式。

## 本機執行
直接用瀏覽器開啟 `index.html` 即可。
